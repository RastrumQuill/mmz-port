## 1. World model
- One 128x128 chunk grid (rows 0-51 real). Chunk = 15x10 metatiles of 16 px = 240x160.
- sAreaGrid 0x082921EC (low nibble = area, >=0xF0 none, 0x00 unused filler); sChunkCol 0x082915EC, sChunkRow 0x08290DEC.
- sAreaTable 0x08293BEC: [12][3] AreaDesc (0x88 B; areas 9-11 share). Fields: id+0, funcs+4, tileSet+8, layouts[3]+0xC,
  bgId+0x18 (0x12/0x24/0x38=BG1/2/3), prio+0x24, scrbase+0x30, scale[3][2]+0x3C (8.8), offset[3][2]+0x54 (px),
  left/top+0x6C/+0x70 (chunks), gfxMap+0x74, layerHandlers+0x78 (12 B: update,draw,leave), layerMap+0x7C
  (u16 shift, 6 B, u16 cells: bits12-15 level, 8-11/4-7/0-3 handler idx of layers 0/1/2).
- sStageAreaVariants 0x0829FD94: 2 bits per area. Mission->area/variant: m1,m2 a0 v1/v2; m3,m4 a1; m5,m6 a2 (m5 train);
  m7,m8 a3; m9,m10 a4 (desert); m11,m12 a5; m14 a6 v1; m15 a7 v1; m16 a8 v1. (verified headless: m5,m7,m9.)

## 2. Camera
- gCamera 0x02022C44: mode+0x18, chaseMode+0x19, shake+0x28, target+0x30, x/y+0x38 (screen centre, 24.8), speed+0x40,
  follow+0x48, dx/ddx/dy/ddy+0x4C, left/right/top/bottom+0x5C.
- Modes: 0 none (stage BGs saved+off); 1 forced scroll; 2 follow+offset; 3 follow (x step 4 px/f, y closes 1/8 per frame,
  Zero 16-24 px below centre); 4/5 as 3 but clamped to limits, step 3.5 px.
- chaseMode: 0 jump, 1 quarter distance, 2 ease 1024 f, 4 ease 256 f; flag 8 easing; 0x10 ignore horizontal edge pull.
- Edge pull (sub_080066F8): on 120x80 px cells, if layerMap level 120 px left/right or 80 px up/down differs by >1 or is 15,
  centre snaps so the screen edge stops at that boundary. sub_080066AC: camera freezes while followed point is on grid
  high nibble 15 or level 15. **The wide view must use the same level rule to decide what neighbouring space is visible.**
- Limits: sStageCamera template 0x0829FDD8; cutscene op 4 (template), op 5 arg 11-14 (limits), arg 0 (mode), 16 (camera+BGs
  off), 17 (back to mode 3); op 7 follow player; op 11 spawn actor (slot 0 = player); op 12 arg2=0 teleport. Stage events
  also set limits (stage_events.c:167 boss lock). During normal play mode 3 with limits 0.
- Doors (kind 6 subtype 8): player walks 56 px; at timer 28 camera targets 0x38 px ahead; door closes.
- Stage_Init re-run mid-stage (m5 stage_events.c:294; m16 :1534) -> treat as full area reset.
- Shake_Update: level = max source x256, decays x15/16; x random +-level/16, y sine period 4 f; added to layer viewOffset.

## 3. Layers
- sub_080061F8: area = GetAreaAt(screen top-left). Area change -> reload metatiles, funcs[0], reset layers; each frame funcs[1]
  + Stage_UpdateLayer per layer. Layer pos = screen top-left in area-local px.
- Handler chosen from layerMap cell under screen top-left; change sets BG on/off, BGCNT = prio|scrbase|0x6044, scale/offset.
- **scroll = pos*scale>>8 + offset + shake**. Layer 0 draws gStage.metatiles (layout 0 + runtime patches via
  Stage_SetMetatiles/LoadChunkMetatiles); layers 1/2 draw layouts[1]/[2], same tile set.
- No repeat in data: BgLayer_Redraw clamps negative pos to 0, only 512 px HW wrap. Backdrop repeat in wide view = port extension.
- Stage_DrawNextAreas draws right/below neighbour area edges at that area's own layer-0 scale.

## 4. Graphics sets
- gfxMap (shift, unk, w, h, sets[]): set byte high nibble slot0, low nibble slot1; 14 = use chunk to the right, 15 = chunk below.
- Stage_LoadGfxSets (sub_08006D3C) loads only the set of the chunk at screen top-left; gStage.gfxSlots 0x02005430/32 = area<<8|set.
  **Wide view: neighbouring chunks may need a different set -> decode per chunk and keep a set cache.**
- sStageGfxSets 0x086B0000[AreaDesc.id] -> offset to 0x14-byte entries (GfxDesc 12 + PalDesc 8).
  GfxDesc: dataOffset (rel. to desc), info (size bits0-21, slot bits22+), chunkSize, flags (1 chunked, 2 LZ77, bits3-10 slot stride);
  dest = 0x4000 + (flags&0x7F8)*(info>>22). PalDesc: dataOffset, size, compressed, slot*0x20.
- Implemented in port/view.c load_set_tiles / load_set_pal / lz77. Stage_RestoreBgControl reloads sets after cutscenes.

## 7. Rules for the renderer
1. Area = area of the screen top-left; render only chunks of that area (grid nibble), plus Stage_DrawNextAreas right/below edges.
2. Visibility beyond 240x160: stop at layerMap level steps >1 / level 15 (same as edge pull) and at separate_room/room_edge rows;
   hide foreign chunks; respect active camera limits (template/op5/events) as hard view bounds.
3. Per layer: pick handler from layerMap cell at screen top-left; scroll = pos*scale>>8 + offset + shake, plus handler overrides.
4. Layer 0 from live gStage.metatiles (patches), layers 1/2 from layouts; no data repeat (repeat only as an extension).
5. Per-chunk gfx set (14/15 indirection); per-line effects by line function; m5 train/far layer state from RAM.
6. Mode 0 / op5 arg16 -> BGs off; Stage_Init mid-stage -> full reset; doors/teleports -> snap, no interpolation.
